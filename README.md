# Сайт для компьютерного класса — опрос

Демо-сайт на русском языке. Ученики отвечают на вопросы, а сайт справа сам собирается под их ответы
(стиль, цвет, разделы). Результаты опроса приходят на почту.

## Как это устроено: сайт, который пишет сам себя

У каждого **вопроса** есть свой маленький **кусочек кода** (`apply`) для каждого варианта ответа
(файл `js/questions.js`). Движок (`js/engine.js`) после каждого ответа собирает из кусочков готовый CSS
и список разделов и вписывает их в страницу. Поэтому не нужно делать отдельный сайт на каждое сочетание
ответов: 4–11 вопросов по 5–7 вариантов — это миллионы сочетаний, а кусочков кода всего 20–77.

- `js/questions.js` — вопросы и кусочки кода для ответов
- `js/engine.js` — собирает сайт из выбранных кусочков
- `js/features.js` — разделы сайта (текстовые задания, голосовые, тесты, игры)
- `css/site.css` — оформление демо-сайта через переменные; `css/app.css` — оформление страницы опроса
- `config.js` — почта, на которую приходят ответы

### Добавить вопрос

В `js/questions.js` добавь ещё один блок `Engine.register({...})` — больше ничего менять не нужно.

### Добавить раздел сайта

Опиши его в `js/features.js` (по образцу `game`) и добавь вариант ответа с `ctx.feature('имя')`.

## Как подключить почту

Сайт статический, письма отправляет бесплатный сервис [FormSubmit](https://formsubmit.co).

1. В `config.js` впиши адрес в поле `EMAIL`.
2. Один раз пройди опрос и отправь ответ — на почту придёт письмо с кнопкой **Activate**. Нажми её.
3. Дальше каждый ответ приходит отдельным письмом.

Совет: после активации FormSubmit присылает «секретный адрес» вида `a1b2c3…`. Впиши его в `EMAIL` вместо
настоящей почты — тогда почта не будет видна в открытом коде.

## Запуск у себя

Откройте `index.html` в браузере. Запись голоса работает только по `https://` или с `localhost`.
