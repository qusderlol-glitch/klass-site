# Сайт для компьютерного класса

Начало — **`index.html`**: выбор «Я ученик / Я учитель / Анкета» и туториал «кто для кого»
и «кто кому что отправляет».

- **Кабинет учителя** (`teacher.html`) — урок на сегодня (тема, сообщение, задания) → код урока, ссылка и QR-код,
  показ на проекторе, ответы к контрольным (по коду `TEACHER_PIN` из `config.js`), таймер, «Письма и почта».
- **Тур по сайту** — при первом заходе и по кнопке «?» (и для ученика, и для учителя).
- **Отправка** — ученик сам выбирает, кому отправить анкету и результаты урока (`RECIPIENTS` в `config.js`).
  У кого есть почта — письмо уходит само; у кого нет (учительница в Suhtlus) — ученик копирует готовый текст.

Части для учеников:

1. **Анкета** (`anketa.html`) — в стиле бумажного экзамена: листы в клетку лежат на парте, листаешь вниз — следующий лист выезжает снизу. Ответы отмечаются «синей ручкой», в конце — штамп «СДАНО». Пока отвечаешь, на жёлтом стикере видно, как собирается сайт.
2. **Сайт класса** (`site.html`) — собирается сам по ответам анкеты:
   - **Главная** — приветствие, урок сегодня, прогресс, объявления;
   - **Задания** — текстовые (черновик сохраняется сам) и голосовые (запись с микрофона);
   - **Контрольные** — таймер, разные типы вопросов, устный вопрос голосом, оценка и разбор ошибок;
   - **Игры** — «Найди пару» и «Правда или ложь»;
   - **Клавиатурный тренажёр** — скорость, точность, подсветка следующей клавиши;
   - **Мои результаты** и **Настройки** (там же код, который сайт написал сам).

## Как это устроено: сайт, который пишет сам себя

У каждого вопроса анкеты есть маленький **кусочек кода** (`apply`) для каждого варианта ответа (`js/questions.js`).
Движок (`js/engine.js`) после каждого ответа собирает из выбранных кусочков готовый CSS и список разделов
и вписывает их в страницу. Поэтому не нужно делать отдельный сайт на каждое сочетание ответов:
6 вопросов дают сотни сочетаний, а кусочков кода всего около 20.

| Файл | Что внутри |
| --- | --- |
| `js/questions.js` | вопросы анкеты и кусочки кода для ответов |
| `js/engine.js` | собирает сайт из кусочков, сохраняет ответы |
| `js/exam.js`, `css/exam.css` | анкета-экзамен |
| `js/site/data.js` | **содержимое**: урок, объявления, задания, контрольные, тексты тренажёра |
| `js/site/pages.js`, `js/site/games.js` | страницы, игры и тренажёр |
| `js/site/app.js` | меню, переходы, применение темы |
| `css/site.css` | оформление сайта через переменные |
| `config.js` | почта, на которую приходят анкеты |

- **Добавить вопрос** — ещё один `Engine.register({...})` в `js/questions.js`.
- **Поменять задания и контрольные** — только `js/site/data.js`.

Результаты учеников хранятся в браузере на том компьютере, где они работают.

## Как подключить почту

Письма отправляет бесплатный сервис [FormSubmit](https://formsubmit.co).

1. В `config.js` → `RECIPIENTS` впиши адрес в поле `email` нужного адресата.
2. При первом письме на этот адрес придёт письмо от FormSubmit с кнопкой **Activate**. Нажми её один раз.
3. Дальше каждая анкета и каждый отчёт приходят отдельным письмом.

После активации FormSubmit присылает «секретный адрес» вида `a1b2c3…` — его можно вписать в `email` вместо почты,
тогда настоящий адрес не будет виден в открытом коде.

## Запуск у себя

Нужен любой простой сервер, например `python -m http.server`, потом открыть `http://localhost:8000`.
Запись голоса работает только по `https://` или на `localhost`.
